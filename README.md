## 1. Project Overview

### 1.1 The Problem
 University students are required to manage multiple responsibilities across academic, personal, physical, and social aspects of their lives, including assignments, examinations, part-time work, social commitments, and everyday errands, which may overlap and create an unbalanced workload. When students are unable to recognise and manage these demands effectively, they may experience increasing stress, difficulty prioritising tasks, insufficient rest, and a greater risk of burnout. Although productivity and wellbeing applications are available, many focus primarily on tracking or reporting, while students may still need separate tools to organise responsibilities and access recovery activities. Furthermore, students who are already busy or overwhelmed may be less motivated to use applications that require lengthy input or frequent manual interaction. Therefore, there is a need for an all-in-one application that provides a clear overview of workload across different areas of life and supports students in taking practical action before burnout occurs.

## 5. Technical Architecture & Feasibility

### 5.1 Tech stack

The frontend of the application is styled using Cascading Style Sheet (CSS) and built using JavaScript and React with TypeScript and Vite. CSS allows the implementation of light or dark mode themes and responsive layouts across mobile phones. TypeScript acts as a build-time tool that catches bugs and errors early, and adds optional static typing to JavaScript, making it easier to build and maintain large-scale applications, while Vite used to speed up development and create optimized production files for web applications.

As for backend infrastructure, it relies on Laravel server frameworks paired with structured MySQL databases. MySQL was chosen as it is highly optimized for fast data retrieval and efficient relational querying, which are essential for organizing complex user task hierarchies, priority and completion histories. The backend integrates an AI vision engine to automatically scan and extract the task titles, due dates and its priority based on the image uploaded by the user. In addition, an integrated auto-sync technology was used for smartwatch, google calendar and student email to ensure that task status changes are continuously saved and reflected across active application views. The application will be deployed using modern web hosting platforms.

### 5.2 Build plan & scope

The current build plan focuses more on delivering all core features in the project structure such as cross-platform technology, extracted tasks from image and text and database synchronisation. Advanced capabilities that are planned to be added to the application are connections to third party ecosystems such as Spotify and Google Calendar, adding a social study room where the users can interact online with friends and real-time multi-device synchronization which eases users to look at any devices that have been sync to the app. Keeping the initial scope focused on core features makes the project realistic, achievable and stable for testing.
